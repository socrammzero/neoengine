Número de Trazas en el Árbol de Entrelazado P(n=2) || Q(m=3)

Dados los procesos secuenciales P = p1 → p2 (n = 2 instrucciones atómicas) y Q = q1 → q2 → q3 (m = 3 instrucciones atómicas), calcula el número total de trazas posibles de P || Q sobre un monoprocesador sin solapamientos.

Solución Razonada Paso a Paso (Tema 1, Págs. 11, 12 y 16)
Ntrazas = (m + n)! / (m! · n!) = (3 + 2)! / (3! · 2!) = 5! / (6 · 2) = 120 / 12 = 10 trazas

Las 10 trazas conservan el orden parcial relativo p1 → p2 y q1 → q2 → q3 (ejemplos similares en diapositivas 11 y 12 del Tema 1).

Cálculo Combinatorio de Trazas para P(n=4) || Q(m=3)

Si el proceso P ejecuta n = 4 instrucciones máquina atómicas y el proceso Q ejecuta m = 3 instrucciones máquina atómicas, ¿cuántas trazas de ejecución posibles deben ser correctas para garantizar que el programa concurrente P || Q sea correcto?

Solución Razonada Paso a Paso (Tema 1, Pág. 16)
Ntrazas = (3 + 4)! / (3! · 4!) = 7! / (6 · 24) = 5040 / 144 = 35 trazas

Según la página 16 del Tema 1 ("Para que un programa P||Q sea correcto deben serlo todas sus trazas de ejecución"), las 35 trazas deben ser válidas.

Permutaciones de Asignaciones Independientes (x = 0 || y = 0 || z = 0)

Instrucciones Máquina de la Sección Crítica en las Taquillas

En la descomposición en ensamblador del código de las máquinas vendedoras de entradas (Tema 1, págs. 29–32), ¿cuántas instrucciones máquina componen el bloque azul marcado como Sección Crítica (desde load asiento[a] to CPU register hasta set asiento[a] to true inclusive)?

Solución Razonada Paso a Paso (Tema 1, Págs. 29–32)

Las 4 instrucciones máquina de la Sección Crítica son: (1) load asiento[a] to CPU register, (2) test the value of CPU register, (3) jump to L1 if true, y (4) set asiento[a] to true.
