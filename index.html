2. Directivas Críticas de Codificación para Examen (Estándar INFO.md) Cumplimiento Estricto

Prohibiciones Estrictas que Invalidan un Ejercicio de Examen
  1. PROHIBICIÓN ABSOLUTA DE volatile: Jamás se utiliza la palabra clave volatile en ninguna variable, parámetro o puntero (ni en espera activa, ni en semáforos, ni en ninguna parte). Toda variable compartida se define como global estándar (int, unsigned, long).
  2. PROHIBIDO EL USO DE pthread_mutex_lock: Para exclusión mutua debe usarse obligatoriamente un semáforo sem_t mutex inicializado con sem_init(&mutex, 0, 1) y operado con sem_wait(&mutex) y sem_post(&mutex).
  3. PROHIBIDO EL USO DE (void*)(intptr_t)i EN pthread_create: Debe declararse int ids[MAX], asignar en bucle ids[i] = i; y pasar &ids[i] en pthread_create(&th[i], NULL, Tarea, &ids[i]).
  4. OBLIGATORIO COMPROBAR ERRORES: Toda llamada a pthread_create y pthread_join debe validar su valor devuelto (if (pthread_create(...) != 0) { perror(...); exit(-1); }).
Compilación Oficial POSIX:   gcc -Wall -Wextra -std=c11 -pthread programa.c -o programa -lrt

3. Simulador Interactivo: Explosión Combinatoria de Trazas de Entrelazado (Interleaving) Tema 1 · Pág. 16

Si el proceso P = p1 → p2 → … → pn tiene n instrucciones atómicas y el proceso Q = q1 → q2 → … → qm tiene m instrucciones atómicas, el número total de trazas posibles de P || Q conservando el orden parcial interno es:

Ntrazas(n, m) = (m + n)! / (m! · n!)   |   Para k procesos de n instrucciones: (k · n)! / (n!)k
